02How it works

Magia speaks the app's own encrypted protocol. Requests are hex(base64(3DES(json))); media rides the same Cloudflare CDN the official app uses.

magia — python3 magia.py
  ┌─ Authentication ──────────────────────────────┐
    1  Free tier (no login)   auto-activates
    2  Login with account     email + password
    3  Register               email + code + password
    4  Recover password       code sent to email

  >  Live TV  ›  ESPN Deportes HD
  i  Resolving live stream (CDN cfl)…
  i  Signing segments (sign_o3)…
  >  Opening in VLC  →  http://127.0.0.1:8788/live.m3u8
  >  Playing. Re-signing each .ts segment on the fly.

03Live TV — the flagship 📡

Live was the hardest part of the app to reverse. The player hid it behind a proprietary nvuos/SLB binary protocol — a dead end. The breakthrough: live rides the same Cloudflare CDN as VOD via sign_type=cfl, plain HLS with one twist — every segment must be freshly signed.

live path — resolve → playlist → sign → play
1. play_live(ch)        → liveAddressList[0].license  (Content-License)
2. get_slb(merge,[ch])  → cdn_list[tag=live, sign_type=cfl]
                        main_addr = cfl host (rotates)   url = auth base + token=<32 hex>
3. GET http://<cflhost>/live/<ch>.m3u8      → m3u8, absolute segment URLs
4. per .ts:  …/<ch>_shisui_<ts>.ts?&sign2_method=sign_o3
              &start_moment=<ms>&sign2=sign_o3(token, moment)
                        → 200 OK, MPEG-TS (0x47…). Segments expire in seconds.
🧬

sign_o3 — tweaked MD5

Each segment needs a signature from a patched MD5 in libranger-jni.so — plain hashlib.md5 won't match. Recovered by hooking MD5_Update with Frida to dump the message + SALT, then emulating the compression function with Unicorn for byte-identical digests.

🔀

Local HLS proxy

Since segments expire in seconds, no static playlist works. live_cfl.py runs a tiny proxy that re-signs each .ts on demand, so any player just opens a normal http://127.0.0.1:PORT/live.m3u8.

Standalone: python3 live_cfl.py <channel> --play  ·  full write-up in MAGIA_RUNBOOK.md.

04What was cracked

Reverse-engineered from the com.xuper.netxxus APK with jadx, Frida and Unicorn — then rebuilt so nothing Android is needed at runtime.

Portal protocol
3DES-ECB body cipher — every request/response is hex(base64(3DES(json))). Key lifted from the native .so.
VOD delivery
Movies & episodes download straight from Cloudflare CDN (sign_type=cfl) with an interchangeable, ~48h auth token.
Live TV · cfl
Discovered live rides the same CDN as VOD: /live/<ch>.m3u8 with rotating hosts and per-segment auth.
Live TV · sign_o3
Each .ts needs a fresh signature from a tweaked-MD5 native routine — emulated with Unicorn and re-signed live by a local proxy.
Accounts
Login/registration/reset reproduced — including the exact MD5(password + "cloudstream") hashing, so accounts work in the app too.
SVS / nvuos
The proprietary auth= cipher (AES + a custom base64 alphabet) was fully cracked too — kept as plan B; the cfl path made it unnecessary.

05Install

Python 3.8+. Secrets live in a git-ignored .env — nothing is hardcoded.

One-line install

# macOS / Linux
$ curl -sL https://raw.githubusercontent.com/lordmacu/magia/main/install.sh | bash

# Windows (PowerShell)
> powershell -c "irm https://raw.githubusercontent.com/lordmacu/magia/main/install.ps1 | iex"

Or manually

$ git clone https://github.com/lordmacu/magia.git
$ cd magia
$ pip install pycryptodome requests
$ cp .env.example .env   # fill in your values
$ python3 magia.py

Full technical write-up — how every value was obtained and how to re-derive it if the provider rotates keys — is in MAGIA_RUNBOOK.md.
