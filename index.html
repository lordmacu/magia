Features

Everything the app does, without the app.

Magia reverse-engineers the full IPTV portal protocol — encrypted API calls, CDN auth tokens, device fingerprinting — and reimplements it in pure Python.

🔍

Search & Browse

Search by name, genre, year, country, or actor. Browse the latest releases or get recommendations based on what you like.

🎬

Download Movies

View full details — cast, score, description — then download in your preferred quality. H.264/MP4 preferred, H.265/TS fallback.

📺

Download Series

Pick all episodes, a range, or just one. Auto-organized in named folders: Dragon_Ball/ep001.mp4.

📡

Live TV

Browse 1,000+ channels across 30+ categories. Get stream credentials for your external player.

🔒

Zero Secrets in Code

All credentials, keys, and device fingerprints live in .env. Nothing hardcoded, nothing committed.

⚡

Rate-Limit Aware

Respects API rate limits (1.5s between calls), auto-refreshes CDN tokens every 30 episodes, recovers from expired sessions.

Under the Hood

Reverse-engineered from the ground up.

The IPTV app encrypts every API call with 3DES and speaks a proprietary binary protocol for CDN auth. Magia reimplements all of it in ~800 lines of Python.

1

Encrypt & Authenticate

Every request body is JSON → 3DES-ECB encrypted → Base64 → Hex encoded. Device fingerprint fields are injected into every call. The server issues a session token on activation.

2

Search & Resolve Content

Search returns content IDs from a 44,000-item catalog. For movies, play_vod() returns stream metadata — media codes, licenses, available formats. For series, episodes() lists all episodes first.

3

Get CDN Authorization

get_slb() returns Cloudflare CDN auth tokens — signed URLs with expiration timestamps (~48h). These tokens work across sessions and auto-refresh every 30 episodes.

4

Direct Download

A simple HTTP GET to the Cloudflare CDN with Content-Auth and Content-License headers streams the raw MP4/TS file. No proxy, no player app — just bytes on disk.

Reverse Engineering Stack

How the protocol was discovered — from APK to pure Python.

jadx

Decompiled the APK to Java source. Found the 3DES crypto path, OkHttp interceptors, and device fingerprint injection.

apktool

Extracted resources, smali code, and the native .so libraries that contain the crypto key material.

Frida

Runtime instrumentation on a rooted emulator. Hooked NativeJni.Call(), OkHttp, java.net.URL to capture the live protocol.

Python

Full protocol reimplementation: 3DES crypto, device spoofing, CDN auth, VOD downloads. ~800 lines, zero native deps.
